# Data Directory

This directory contains datasets for the Hiver SDE assignment.

## Files

- `gold_set.jsonl` - Gold standard dataset with labeled examples

## Format

Dataset files use JSONL (JSON Lines) format where each line is a valid JSON object.

Example:
```json
{"id": "1", "query": "How do I reset my password?", "intent": "support", "response": "You can reset your password by..."}
```
